# Vid-show

Лёгкий видеоплеер для Windows на два экрана:

- **Пульт** (ваш экран): превью, таймлайн, старт/пауза, плейлист, громкость, скорость.
- **Проектор** (второй экран): только видео, на весь экран, без рамок и курсора.

## Использование
1. Перетащите видео в окно (или «＋ Добавить») — можно сразу несколько, они сыграют по очереди.
2. Выберите монитор проектора (кнопка «Экран N») и нажмите **«Показать на проекторе»**.
3. Если монитор один, проектор открывается обычным окном — удобно проверить.

## Очередь: картинки ожидания и бесшовные переходы
- В очередь можно класть и видео, и картинки (jpg, png, bmp, gif, tif).
- **Картинка ожидания** (`∞ Ждать`, включено по умолчанию для картинок): висит на проекторе, пока вы не нажмёте `Пробел` или `N` — тогда следующий элемент включается сразу.
- Остальные картинки показываются N секунд (кнопка «Таймер картинки»), потом очередь идёт дальше сама.
- Следующий элемент **заранее подгружается** в скрытый слой и плавно проявляется поверх текущего (кнопка «Переход»: резкий / 0.5 / 1 / 2 / 3 с); звук тоже сводится плавно. Видео-в-видео переход начинается заранее, чтобы закончиться ровно с концом ролика.
- Порядок меняется кнопками ▲ ▼, очередь запоминается между запусками.

## Программа мероприятия (монтаж показа)
Каждый элемент очереди — это «cue» со своими свойствами (кнопка ⚙ или клавиша `E`):
- **Обрезка:** «Начать с» и «Снять на» — какой кусок видео играть. Время можно взять прямо с плеера кнопкой «⏱ Взять с плеера».
- **Повтор:** сыграть N раз или **по кругу, пока не нажмёте «дальше»** (зацикленная петля-фон, кусок видео в цикле).
- **В конце:** `⏸ Ждать оператора` (остаться на последнем кадре) или `◐ Затемнить и ждать`.
- **Переход:** своя длительность наплыва, либо **через чёрное**.
- **Фанфара при старте:** звук проигрывается в момент включения элемента (музыка на это время тише).
- **Музыка:** элемент может сам включить или плавно выключить фон.
- **⬛ Чёрный экран** — вставка паузы между блоками (ждёт оператора или держится N секунд).
- **🗓 План** (`G`) — карта всей программы: блоки с длительностями и временем старта, паузы ⏸, повторы, переходы; блоки перетаскиваются, двойной клик — включить.
- Программу можно **сохранить в файл** (`.vshow`) и открыть на другом компьютере (пути к файлам должны совпадать).
- `Пробел` на элементе, который ждёт, включает следующий. `Shift+Пробел` — обычная пауза.

## Звук: устройство вывода, фанфары
- Музыка и эффекты идут на выбранное устройство (кнопка «🔈» во вкладке «Музыка»), повтор одного трека — **без паузы** на стыке.
- 6 кнопок **фанфар и эффектов** (клавиши `1`–`6`): левая кнопка мыши — играть, правая — назначить звук.
- Звук видео идёт на устройство Windows по умолчанию; для другого — кнопка ⚙ рядом (настройки громкости приложений Windows).

## Фоновая музыка
Вкладка **🎵 Музыка** справа — отдельный плеер, не зависящий от видео-очереди (мини-плеер с ▶/❚❚ виден на любой вкладке).
- Свой плейлист (mp3, wav, wma, m4a, aac, flac, ogg; flac/ogg — только на Windows 10+), перетаскивание файлов в окно.
- Режимы: **список по кругу**, **один трек по кругу**, один раз; случайный порядок.
- **Плавно вкл / выкл** (3 с) и мягкий старт трека — без резкого звука в зале.
- **Приглушать** — музыка сама становится тише, пока идёт видео со звуком, и возвращается после.
- Картинка ожидания + музыка = фон зала. `K` — музыка пуск/пауза, `Ctrl+↑/↓` — громкость музыки.

## Таймлайн-раскадровка
Вместо полоски — кадры видео по всей длине ролика (как в видеоредакторе): кликайте или тяните по кадрам, чтобы перемотать, над кадрами показывается время под курсором. Затемнена ещё не сыгранная часть, белая линия — текущая позиция. Кадры снимаются в фоне за пару секунд после запуска ролика; на слабых ПК отключается кнопкой «Превью».

## Фишки
- **Чёрный экран** на проекторе (плавное затухание), видео продолжает идти.
- Плейлист с автопереходом, повтор, скорость 0.5×–2×, превью можно выключить для слабых ПК.
- Компьютер не засыпает во время показа; настройки запоминаются; монитор подхватывается при переподключении проектора.
- «Открыть с помощью» и перетаскивание файла на `VidShow.exe`.

## Горячие клавиши
`Пробел` пуск/пауза · `B` чёрный экран · `F` проектор · `M` звук · `L` повтор · `←/→` ±5 с (`Shift` ±30 с) ·
`N/P` следующее/предыдущее · `S` стоп · `Home` в начало · `Del` убрать из списка · `Esc` скрыть проектор

## Требования и производительность
- Windows 7 SP1 / 8 / 10 / 11, .NET Framework 4.8 (встроен в Win10 1903+ и Win11). Exe ~100 КБ.
- Кодеки — системные Windows. Если MP4 не играет на Win7/N-редакциях — поставьте пакет кодеков.
- Слабый ПК: выключите «Превью», либо запускайте `VidShow.exe --software`.
