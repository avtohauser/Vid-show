# Vid-show

Лёгкий плеер для Windows на два экрана:

- **Пульт** (ваш экран): превью, таймлайн, Старт/Пауза, Стоп, повтор, громкость.
- **Проектор** (второй экран): только видео, на весь экран.

Использование: открыть видео (или перетащить файл в окно) → выбрать экран проектора → «Показать на проекторе».
Пробел — старт/пауза, ←/→ — перемотка на 5 с.

Сборка: GitHub Actions (вкладка Actions → артефакт `VidShow-win-x64` → `VidShow.exe`, установка не нужна)
или локально: `dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true`.
Кодеки — системные Windows (MP4/H.264 работает из коробки).
